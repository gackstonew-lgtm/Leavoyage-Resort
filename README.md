Le Voyage Resort 🏨🌴

**Le Voyage Resort** is a modern, high-conversion luxury resort and hospitality web application designed to deliver a seamless booking experience for guests and comprehensive booking management for resort operators. Built with high performance, elegant UI transitions, and robust serverless architecture, the application provides real-time room availability, interactive amenity showcases, and direct booking processing.

---

## ✨ Key Features & Experience

### 🏨 Guest Experience & Hospitality
* **Interactive Room Showcase:** Visual suite exploration with high-definition imagery, detailed amenity breakdowns, dynamic pricing, and occupancy limits.
* **Direct Booking & Reservation Engine:** Real-time date pickers, stay duration calculation, and instant booking submission.
* **Resort Amenities & Experiences:** Curated guides covering dining options, spa packages, outdoor excursions, and private event hosting.
* **Responsive Luxury Design:** Optimized for mobile, tablet, and desktop viewing with smooth animations and intuitive user flows.

### ⚡ Performance & Technical Highlights
* **Serverless Deployment:** Hosted on **Vercel** with global CDN edge distribution for ultra-fast load times.
* **SEO & Social Optimization:** Server-side metadata rendering, OpenGraph social preview tags, and structured schema markup for search engines.
* **Form Handling & Notifications:** Integrated reservation workflows with instant client and staff confirmation triggers.

---

## 🛠️ Tech Stack

* **Frontend Framework:** Next.js / React
* **Styling & UI Components:** Tailwind CSS, Lucide Icons, Framer Motion
* **Type Safety:** TypeScript
* **Hosting & CDN:** Vercel Edge Network
* **Form Management & API:** Next.js Server Actions / API Routes
